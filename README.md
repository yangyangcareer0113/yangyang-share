# yangyang-share

楊楊教練公開分享用檔案（講義、單頁工具等）。透過 GitHub Pages 提供可直接開啟的公開連結，取代 Gist + htmlpreview.github.io（不穩定，且中文檔名易失敗）。

## 使用規則

- 檔名一律用英文/數字，避免中文或特殊字元（Gist+htmlpreview 失敗的根本原因之一）
- 新增檔案後 push 到 main，GitHub Pages 會自動更新
- 網址格式：`https://yangyangcareer0113.github.io/yangyang-share/<檔名>`
